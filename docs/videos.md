# Videos

These videos were generated with AI to present `rp2350sim`'s features in
situation. They are narrated tours of real firmware running in the emulator;
the production and voice are AI-generated. A new episode is added when a batch
of features lands, so check the [release notes](release.md) for the latest
state.

## RP2350 simulator introduction

[![RP2350 simulator introduction](https://img.youtube.com/vi/I7zEjE-_OwE/hqdefault.jpg)](https://youtu.be/I7zEjE-_OwE)

[Watch on YouTube](https://youtu.be/I7zEjE-_OwE) — presents the project, the
Cortex-M33 interpreter, TinyGo and Pico SDK C firmware, the board picker and
the emulator's main interfaces.
